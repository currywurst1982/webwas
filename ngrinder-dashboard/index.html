용어 설명
  • Vuser: 가상 사용자 수. nGrinder에서는 에이전트 1대당 Vuser = 프로세스 수 × 스레드 수 입니다.
  • TPS: 초당 처리한 테스트(요청) 건수.
  • Peak TPS: 테스트 중 가장 높았던 TPS.
  • MTT (Mean Test Time): 테스트 1건의 평균 소요시간(ms). 응답시간이라고 보면 됩니다.
  • 에러율: 에러 수 ÷ (성공 테스트 수 + 에러 수) × 100.
  • Ramp-up: 부하를 한 번에 주지 않고 프로세스나 스레드를 정해진 간격마다 늘려 가는 설정.
  • 웜업: 서버를 새로 띄운 직후의 불안정한 상태가 결과에 섞이지 않도록 본 측정 전에 미리 부하를 주는 것.
  • 모니터 에이전트: 테스트 대상 서버에 설치해 CPU·메모리를 nGrinder로 보내는 프로그램. 설치하지 않으면 ② 아래 "대상 서버 자원"이 비어 있습니다.

테스트 진행 권장 순서: ① 스모크(아주 적은 Vuser로 스크립트·연결이 정상인지 확인) → ② Vuser를 단계적으로 늘려 가며 반복 실행(④ 그래프로 포화점 확인) → ③ 목표 부하로 30분 이상 유지하며 메모리가 계속 늘어나는지(누수) 확인.
