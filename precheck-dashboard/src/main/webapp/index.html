에이전트 서버

    아직 등록된 점검 결과가 없습니다

    1. 왼쪽 에이전트 서버 → 에이전트 관리 → 에이전트 추가를 누르고, 안내되는 명령으로 점검할 웹서버에 에이전트를 설치합니다.
    2. 설치되면 에이전트가 점검 스크립트를 실행해 결과를 자동으로 보내고, 이 화면에 표시됩니다. (지금 점검으로 바로 실행 가능)
    3. 에이전트를 설치할 수 없는 서버는 sudo bash apache_precheck.sh 결과 파일을 리포트 업로드로 올려도 됩니다.
