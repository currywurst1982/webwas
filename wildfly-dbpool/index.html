WildFly 26 DB Connection Pool Manager
Linux WildFly 26 DataSource 풀 상태 확인 & 설정 자동 생성

WildFly CLI 명령어 — DS_NAME을 실제 DataSource 이름으로 변경하세요

① 통계 수집 활성화 (서버 재시작 불필요)
/subsystem=datasources/data-source=DS_NAME:write-attribute(name=statistics-enabled,value=true)
② 풀 전체 현황 조회
/subsystem=datasources/data-source=DS_NAME:read-resource(include-runtime=true)
③ 활성 커넥션 수 (현재 사용 중)
/subsystem=datasources/data-source=DS_NAME/statistics=pool:read-attribute(name=ActiveCount)
④ 사용 가능 커넥션 수
/subsystem=datasources/data-source=DS_NAME/statistics=pool:read-attribute(name=AvailableCount)
⑤ 기동 후 최대 사용 커넥션 수
/subsystem=datasources/data-source=DS_NAME/statistics=pool:read-attribute(name=MaxUsedCount)
⑥ 타임아웃 커넥션 수
/subsystem=datasources/data-source=DS_NAME/statistics=pool:read-attribute(name=TimedOut)
⑦ Linux — Java 프로세스 소켓 상태
ss -tlnp | grep java
⑧ PostgreSQL DB 연결 수 확인
netstat -an | grep :5432 | grep ESTABLISHED | wc -l

풀 통계 항목 설명

항목명설명정상 범위주의 조건
ActiveCount현재 사용 중인 커넥션 수max의 80% 이하max 근접 시 풀 확장
AvailableCount즉시 사용 가능한 커넥션 수min 이상 유지0이면 즉시 조치 필요
MaxUsedCount기동 후 최대 사용량max의 70% 이하max 초과 시 리크 의심
TimedOut타임아웃으로 반환된 커넥션 수0증가 시 쿼리 최적화
WaitCount커넥션 대기 발생 횟수0증가 시 max-pool-size 증가
InUseCount현재 대여 중인 커넥션 수-ActiveCount와 비교하여 분석
CreatedCount생성된 총 커넥션 수-급증 시 커넥션 리크 의심
DestroyedCount소멸된 총 커넥션 수-CreatedCount와 비교
